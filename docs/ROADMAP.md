## How We Prioritize

### Framework: RICE Score

| Factor | Weight | Description |
|--------|--------|-------------|
| **R**each | 30% | How many users affected |
| **I**mpact | 30% | How much value delivered |
| **C**onfidence | 20% | How sure are we |
| **E**ffort | 20% | Development cost |

### Priority Definitions

| Priority | Definition | SLA |
|----------|------------|-----|
| P0 | Critical - blocks core workflow | This sprint |
| P1 | High - significant user value | This quarter |
| P2 | Medium - nice to have | Next quarter |
| P3 | Low - future consideration | Backlog |
